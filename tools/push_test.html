通知テスト〈実験〉

PWA の通知がどこまで届くかを実機で測るためのページです。ぽっと通話の本体とは切り離されています。

⚠️ iPhone では「ホーム画面に追加」してから開いてください。

iOS は、ホーム画面に追加した PWA の中でしか通知を出せません（16.4 以降）。Safari のタブのままだと ① で失敗します。
共有ボタン → 「ホーム画面に追加」 → そのアイコンから開き直してください。

いまの環境

手順

① ← 最初に押す（ボタンからでないと許可を求められません）
② ← スコープが /tools/ であることを確認します
③ ← iOS では「ページから」は出ない想定

④ バックグラウンドで何分まで届くか（本題）

押したらすぐホーム画面に戻して、そのまま待ってください。通知の本文に「予定」と「実際」が出るので、ずれとそもそも来たかどうかを見ます。

短いほうから順に試すのがおすすめです。届かなくなったところが、この端末の限界です。

⑤ 本物の Web Push（購読だけ）

購読を作るところまで試します。突く相手（サーバ）がいないので通知は鳴りません。「購読は作れる」ことだけを確かめます。

後片付け

実験が終わったら解除してください。通知の許可はブラウザの設定から取り消せます。
